The one container shape in this system: 1px border, `--color-bg-secondary`, square corners, 3px hard offset shadow. No radius, no soft shadow, no gradient.

```jsx
<Panel path="publication/review" title="review roll publication" tone="amber">
  <p>18 frames · 1 markdown file</p>
</Panel>
```

Tones map to the admin's state colours: `amber` = awaiting review, `blue` = in flight, `accent` = confirmed/active.
