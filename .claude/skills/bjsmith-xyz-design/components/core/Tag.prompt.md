Category and film-stock labels. Bracketed and colour-coded: dev = cyan, art = amber, photography = green; colour film = amber, B&W = grey.

```jsx
<Tag kind="dev">dev</Tag>
<Tag kind="color">Kodak ColorPlus 200</Tag>
<Tag chip>watercolour</Tag>
```

Freeform keywords (entry `tags`) use `chip`: muted text on `--color-bg-tertiary` with a 1px border, no brackets.
